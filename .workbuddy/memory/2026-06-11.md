## Enginefall 页面 CTR 修复

**问题**：GSC 数据显示排名前 2 但 CTR = 0%
- enginefall 主页：排名 1.9，展示 10 次，点击 0
- enginefall/beginner-guide：排名 2.1，展示 10 次，点击 0
- enginefall/playtest：排名 2.8，展示 9 次，点击 0
- enginefall/system-requirements：排名 4.4，展示 18 次，点击 0

**根因**：
1. BLUF 区域包含内部 SEO 笔记（"Worth Doing? Enginefall is worth a real guide cluster..."），Google 把它当 SERP 摘要 → 用户看到的是内部讨论，不点击
2. Title 是关键词堆砌（"Enginefall Guide: Release Date, Gameplay, Steam, PS5, Xbox & Playtest"）→ 看起来像 SEO 页面
3. Description 是功能清单，不是价值承诺

**修复**：修改 `projects/src/lib/enginefall.ts`，6 个页面全部重写：

| 页面 | 原 Title | 新 Title |
|---|---|---|
| hub | Enginefall Guide: Release Date, Gameplay... | Enginefall Guide 2026 - Release Date, Gameplay & How to Get Playtest Access |
| playtest | Enginefall Playtest Dates, Demo, Key... | Enginefall Playtest 2026 - Dates, Demo Access & How to Get a Key |
| beginner | Enginefall Beginner Guide: How to Play... | Enginefall Beginner Guide - How to Survive Your First Run & Extract |
| conductor | How to Become Conductor in Enginefall... | Enginefall Conductor Guide - How to Reach C00, Use Breacher & Extract |
| dagger | Enginefall Dagger Guide: Shuttle Base... | Enginefall Dagger Guide - Shuttle Base, Fuel & Upgrade Priorities |
| platforms | Enginefall System Requirements, Steam Deck... | Enginefall System Requirements 2026 - PC Specs, Steam Deck & Console Status |

- 所有 description 从功能清单改为价值承诺
- 所有 blufTitle/bluf 从内部 SEO 笔记改为用户导向的说明文字

**下一步**：build + deploy，然后等 1-2 周在 GSC 里观察 CTR 变化。
