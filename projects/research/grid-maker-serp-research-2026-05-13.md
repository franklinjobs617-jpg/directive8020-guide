## User Needs Found

### Drawing grid maker

User wants:

- Upload a reference photo.
- Add grid overlay.
- Choose rows/columns.
- Change line color, thickness, opacity.
- Add labels.
- Preserve original image ratio.
- Download PNG/JPG/PDF.
- Print at the right paper size.

Winning feature:

- "Print-ready drawing grid with matching blank grid worksheet."

### Instagram grid maker

User wants:

- Upload one image.
- Crop for Instagram feed.
- Split into 3, 6, 9, 12 tiles.
- Support current portrait-friendly ratios, not only old square tiles.
- Download ZIP.
- Know the exact posting order.
- No watermark.
- Mobile-first UI.

Important Reddit pain signal:

- A Reddit Android app post says existing apps were cutting square format only, while the user wanted 3:4 slicing after Instagram changed ratio behavior.

Winning feature:

- "Instagram grid maker for square, 4:5, and 3:4 feed tiles with posting order guide."

### Crochet grid maker

User wants:

- Upload image.
- Reduce colors.
- Generate a pixel/crochet grid.
- Choose grid size.
- Get C2C / single crochet instructions.
- Download PNG/PDF.
- Track rows.

Winning first-version feature:

- "Free image to crochet grid chart with color count and printable PNG."

Do not overbuild first. Full yarn-brand matching and row-by-row instructions can be V2.

### Hex grid map maker

User wants:

- Blank hex grid.
- Choose width/height, hex size, orientation, line color.
- Export PNG/SVG/PDF/transparent background.
- Sometimes wants Foundry/DND compatibility.

Winning first-version feature:

- "Printable transparent hex grid generator" rather than full D&D map editor.

### Photo grid maker

User wants:

- Multi-photo collage.
- Templates.
- Text/stickers/backgrounds.
- HD export.
- No watermark.

This is more competitive. Build later after the site has authority.

## Recommended MVP

Build a multi-tool site, but only implement the simplest high-intent tools first.

### Page 1: `/drawing-grid-maker`

Required:

- Image upload, processed locally.
- Rows/columns.
- Square-cell mode vs stretch-to-image mode.
- Line color, opacity, thickness.
- Labels on/off.
- Download PNG.
- Print-friendly blank grid download.
- FAQ + How to use + related tools.

### Page 2: `/instagram-grid-maker`

Required:

- Image upload.
- Layouts: 3x1, 3x2, 3x3, 4x3.
- Ratios: square 1:1, portrait 4:5, portrait 3:4.
- Crop preview.
- Download ZIP.
- Posting order guide.
- FAQ.

### Page 3: `/grid-maker-for-drawing`

Same tool as drawing grid, but copy targets:

- "grid maker for drawing"
- "photo grid maker for drawing"
- "reference photo grid maker"
- "proportion grid maker"

### Page 4: `/crochet-grid-maker`

V1:

- Upload image.
- Choose rows/columns.
- Choose max colors.
- Pixelated preview.
- Basic color legend.
- Download PNG.

V2:

- PDF export.
- Row-by-row instructions.
- C2C / SC mode.
- Yarn palette matching.

### Page 5: `/hex-grid-map-maker`

V1:

- Choose hex size.
- Choose columns/rows.
- Flat-top vs pointy-top.
- Line color/opacity.
- Transparent background option.
- Export PNG/SVG.

## Build / No-Build Verdict

Build if:

- You can create a real browser tool, not only text.
- First version ships in 3-5 days.
- You focus on drawing + Instagram first.
- You add crochet/hex as simpler, focused tools rather than full professional products.

Do not build if:

- You only plan to write articles.
- You only want to target `photo grid maker`.
- You cannot support ZIP download for Instagram tiles.
- You cannot produce a cleaner mobile UX than existing small tools.

## Final Priority

1. `drawing grid maker` - best mix of clear intent, lower difficulty, and easy MVP.
2. `instagram grid maker` - higher traffic, higher competition, but good if modern ratios/ZIP/posting order are strong.
3. `grid maker for drawing` - easy supporting page.
4. `crochet grid maker` - low KD and monetization potential, but needs craft-specific accuracy.
5. `hex grid map maker` - good niche if kept simple.
6. `photo grid maker` - later.
7. `css grid maker` - later or separate developer-focused site.
